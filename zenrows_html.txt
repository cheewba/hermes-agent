                                                                            <p class="mb-8 last:mb-0">Scraping with headless browsers like Playwright can be tough without the right stealth capabilities. Patchright offers browser patches designed to help you evade detection on protected sites. But how far can it really take you?</p>
<p class="mb-8 last:mb-0">In this article, you'll learn how to use Patchright for web scraping and evaluate its effectiveness against anti-bot measures. You'll then see the singular technique that guarantees successful scraping at any scale.</p>
<h2 class="h2 text-dark mb-8" style="scroll-margin-top: 100px" id="what-is-patchright">What Is Patchright?</h2>
<p class="mb-8 last:mb-0"><a class="underline hover:text-blue" target="_blank" rel="noopener noreferrer nofollow" onclick="" href="https://github.com/Kaliiiiiiiiii-Vinyzu/patchright?tab=readme-ov-file">Patchright</a> is an improved version of the standard Playwright library designed to evade anti-bot detection during scraping. The library is open-source and available in Python and Node.js.</p>
<p class="mb-8 last:mb-0">Similar to stealth plugins like <a class="underline hover:text-blue" target="_blank" rel="noopener" onclick="" href="https://www.zenrows.com/blog/playwright-stealth">Playwright Stealth</a>, Patchright patches Playwright's automation flags to make it less detectable. These include setting <code>navigator.webdriver</code> to False, changing the <code>HeadlessChrome</code> User Agent flag to Chrome, deactivating pop-up blocking, and more.</p>
<p class="mb-8 last:mb-0">Patchright inherits Playwright's browser automation capabilities and APIs. It's simply a drop-in replacement for Playwright and doesn't require a fresh setup or an overhaul of your codebase if you already have a working <a class="underline hover:text-blue" target="_blank" rel="noopener" onclick="" href="https://www.zenrows.com/blog/playwright-scraping">Playwright web scraping</a> script.</p>
<p class="mb-8 last:mb-0">Let's scrape with Patchright to see how it works.</p>
